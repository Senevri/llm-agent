Before implementing functionality using an external library or framework:

1. Identify the library and its installed version.
2. Read and gather relevant documentation, API references, and examples
   for the features you intend to use.
3. Prefer documentation matching the installed version.
4. Verify unfamiliar classes, methods, parameters, and usage patterns.
5. Base implementation on the gathered documentation, not remembered
   or assumed APIs.
6. If documentation is unavailable or ambiguous, investigate with
   small experiments before committing to an implementation.

Do not guess library APIs when authoritative documentation is available.
gather documentation for intended use, not the entire library.
