# System Info Reference

## Metrics Explained

### Memory (free -h)
- **total**: Total installed memory.
- **used**: Memory currently in use.
- **free**: Memory not used at all.
- **available**: Estimate of how much memory is available for starting new applications.

### Disk (df -h)
- **Size**: Total size of the filesystem.
- **Used**: Space currently occupied.
- **Avail**: Space remaining.
- **Use%**: Percentage of disk used.

### CPU Load (uptime)
- The load average represents the average number of processes in the run queue over the last 1, 5, and 15 minutes.
