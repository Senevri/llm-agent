# Maps

Use for geographic maps, fantasy maps, tactical maps, room layouts, and route maps. First determine which kind the user means; these are not interchangeable.

## Choose the map model
- **Geographic/fantasy:** landforms, coastlines, rivers, settlements, borders, labels.
- **Tactical/battle:** grid or scale, obstacles, cover, units, routes, line of sight if needed.
- **Room/floor plan:** walls, doors, openings, furniture, circulation, labels.
- **Route/transit:** nodes, connections, direction, distances or sequence, legend.

## Plan first
1. Establish canvas orientation, scale or grid, and what the map is for.
2. List required locations/features and their relationships.
3. Choose a visual hierarchy: terrain/walls first, important locations next, labels and symbols last.
4. Define a compact symbol system and legend. Keep each symbol consistent.
5. Reserve space for title, labels, compass/scale, and legend if useful.

## Spatial rules
- Keep routes and connections unambiguous; avoid crossing lines where crossings could be misread.
- Do not place labels over important features. Use leader lines if needed.
- For tactical maps, keep grid spacing and cell centers consistent; distinguish impassable terrain from decoration.
- For floor plans, wall openings must remain visible and doors should not appear to block solid walls.
- For fantasy maps, rivers generally flow downhill and merge toward larger waterways; avoid splitting rivers upstream without a reason.
- Do not imply geographic accuracy or a true scale unless the input supports it.

## Verification
Check that every requested location appears, connections are correct, labels are legible, symbols match the legend, and important routes/features are not obscured. If the map is meant for play, prioritize usability over ornament.
